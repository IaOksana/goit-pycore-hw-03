# goit-pycore-hw-03

Small Python utilities for date differences, lottery-number generation, phone normalization, and upcoming birthdays.

## Project structure

The repository contains independent homework tasks and small reusable examples. Open the source file for a task to see its inputs, processing steps, and output.

## Running the code

Run the relevant `task*.py` file with Python.

This project uses only the Python standard library unless a source file states otherwise.

## Reuse

The implementations are educational examples. Copy the smallest relevant function or class into another project and add validation/tests appropriate to the new context.
